Quick guide

1. Go to Questions → click Import JSON to load your existing question-bank.json.
2. Go to PINs → generate PINs in bulk for your customers.
3. Go to Tasks → edit channels, URLs, and rewards.
4. When ready to sync to live site → Questions page → Export JSON → commit to live repo.
